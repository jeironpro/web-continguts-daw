Objetivo

Diseñar, implementar y entrenar un agente DQN (Deep Q-Network) que aprenda a resolver una tarea en un entorno de vuestra elección, aplicando los conocimientos adquiridos en Deep Learning y Reinforcement Learning durante el curso.

Objetivos de aprendizaje

  • Comprender el ciclo agente-entorno y el framework MDP
  • Implementar el algoritmo DQN con PyTorch
  • Diseñar experimentos y analizar curvas de aprendizaje
  • Aplicar técnicas de Deep Learning a problemas de control
  • Documentar y comunicar resultados de forma clara

Descripción de la Tarea

El alumno/grupo debe entregar un Jupyter Notebook (.ipynb) completamente funcional donde:

Seleccionar o crear un entorno

Podéis elegir entre tres opciones: crear vuestro propio juego con Pygame, utilizar un juego/entorno encontrado en internet, o usar alguno de los juegos de Atari disponibles en gymnasium.farama.org. El entorno debe justificar el uso de DQN (estados de alta dimensionalidad o continuos).

Analizar el entorno

Documentar el espacio de estados, espacio de acciones, estructura de recompensas y condiciones de terminación. Incluir ejemplos de observaciones y episodios.

Implementar el agente DQN

Desarrollar un agente DQN con PyTorch incluyendo: red neuronal para aproximar Q(s,a), Experience Replay Buffer y Target Network. Justificar la arquitectura y los hiperparámetros elegidos.

Entrenar y monitorizar

Ejecutar el entrenamiento registrando métricas: recompensa por episodio, pérdida, epsilon. Mostrar curvas de aprendizaje con media móvil.

Evaluar y analizar

Evaluar el agente entrenado (sin exploración) durante varios episodios. Analizar si el agente ha aprendido, comparar con baseline aleatorio, y discutir posibles mejoras.

Elección del Entorno

Tenéis libertad para elegir el entorno donde entrenar vuestro agente DQN. Las opciones son:

Opción 1: Crear vuestro propio juego con Pygame

Diseñar e implementar un juego desde cero usando Pygame. Esto os dará control total sobre el espacio de estados, acciones y recompensas. Ejemplos: Snake, juego de naves, laberinto, etc.

Opción 2: Usar un juego/entorno de internet

Buscar un entorno ya implementado en repositorios de GitHub o en otras fuentes. Aseguraos de citar la fuente y adaptarlo si es necesario para que funcione con DQN.

Opción 3: Juegos de Atari (Gymnasium)

Usar los entornos clásicos de Atari disponibles en gymnasium.farama.org. Estos entornos son estándar en la investigación de RL y ofrecen un buen desafío.

pip install gymnasium[atari,accept-rom-license]

Componentes del Agente DQN

El agente DQN debe incluir los siguientes componentes fundamentales:

Componente Descripción
Red Q (Q-Network) Red neuronal en PyTorch que aproxima Q(s, a). Recibe el estado y devuelve el Q-valor de cada acción.
Target Network Copia de la red Q que se actualiza periódicamente. Proporciona estabilidad al calcular los targets.
Experience Replay Buffer circular que almacena transiciones (s, a, r, s', done). Se muestrea aleatoriamente para entrenar.
Política ε-greedy Selección de acciones con exploración (random) y explotación (mejor Q). Epsilon debe decaer durante el entrenamiento.

Consejos y Recursos

Tips para el éxito

  • Empieza simple: Probad primero con un entorno sencillo para verificar que DQN funciona
  • Usa semillas: env.reset(seed=42) y torch.manual_seed(42) para reproducibilidad
  • Loggea métricas: Guardad recompensas, pérdidas y epsilon por episodio
  • Entrena sin render: Desactivad la visualización durante el entrenamiento (mucho más rápido)
  • Paciencia: El RL es lento, los agentes pueden tardar miles de episodios en aprender
  • Experimenta con hiperparámetros: Probad diferentes learning rates (0.001, 0.0003, 0.0001)
  • Buffer grande: Usad un replay buffer de al menos 10,000 experiencias
  • Decaimiento de epsilon: Aseguraos de que epsilon llegue a valores bajos (~0.01) al final
